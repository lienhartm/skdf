# Ski Club Guebwiller

- Ski club de Guebwiller
- Chalet refuge du Roedelen

## Demandes

- Refonte du site internet
- Administration d'article/revue de presse/résultats/newsletter

### Refonte du site internet

- Page d'accueil
- Page refuge
- Page club
- Page histoire
- Page actualités
- Page revue de presse
- Page résultats
- Page accès
- Page contact
- Page newsletter
- Page login

### Administration d'articles

L'administration d'article se fait par le biais d'un formulaire avec un typage en markdown.

Les articles sont catégorisé selon le type : 
- refuge
- club
- evenement

Une liste d'articles est affichée sur la page actualités et permet de les supprimer.

### Adminsitration de documents

L'administration de documents se fait par le biais d'un formulaire le choix entre 3 types de documents : 
- résultats
- revue de presse

Une liste de documents est affichée sur la page résultats et permet de les supprimer.

### Newsletters/inscription

#### Newsletters
Un modèle de newsletter est préformaté, il faut juste remplir les champs et l'envoyer.

#### Inscription
Une liste des inscrits ayant accepté de recevoir la newsletter est affichée sur la page newsletter et permet de les supprimer. Cela garantie de ne pas envoyer de newsletter aux personnes qui ne veulent plus en recevoir, seul les inscrits recevront la newsletters.

### Login

Le login se fait par le biais d'un formulaire avec un nom d'utilisateur et un mot de passe. Seul un administrateur peut se connecter et ainsi accéder à l'administration.

Les clés étant remis au ski club de guebwiller qui en sera le seul administrateur.
